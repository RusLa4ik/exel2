# RESTART Sheets

Android-додаток від компанії RESTART для роботи з таблицями онлайн: Excel Online, OneDrive і Google Таблиці в одному вікні.

## Що вміє

- Відкриває Excel Online, OneDrive і Google Таблиці, вхід зберігається між запусками.
- Відкриває таблицю за посиланням, останні 5 посилань запам’ятовуються.
- Приймає посилання з інших додатків через «Поділитися» і відкриває посилання на Google Таблиці та OneDrive за замовчуванням.
- Кнопка «Завантажити» у файловому менеджері OneDrive чи Google Диска бере файл із телефона.
- Експортовані .xlsx і .csv зберігаються у «Завантаження».
- «Режим ПК» відкриває повний редактор Excel Online замість мобільного перегляду.

## Як отримати APK

### Варіант 1: GitHub (без встановлення чого-небудь)

1. Створіть порожній репозиторій на GitHub і завантажте в нього вміст цієї папки.
2. Відкрийте вкладку **Actions**, виберіть **Build APK** і натисніть **Run workflow**.
3. Через 3–5 хвилин у запуску з’явиться файл **RESTART-Sheets-apk**. Завантажте його, розпакуйте й отримаєте `app-debug.apk`.

### Варіант 2: Android Studio

1. Відкрийте цю папку в Android Studio (File → Open).
2. Дочекайтеся синхронізації Gradle.
3. Build → Build Bundle(s) / APK(s) → Build APK(s).
4. Файл буде в `app/build/outputs/apk/debug/app-debug.apk`.

## Встановлення на телефон

Скопіюйте `app-debug.apk` на телефон, відкрийте його й дозвольте встановлення з цього джерела, коли Android запитає. Потрібен Android 10 або новіший.

## Для публікації в Google Play

Debug-збірка підписана тимчасовим ключем. Для магазину створіть власний ключ (Build → Generate Signed Bundle / APK) і збирайте release.
